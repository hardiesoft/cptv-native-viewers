CPTV Native Viewers is installed.

If VLC is open, quit and reopen it once so it loads the plugin. After that, double-clicking a .cptv file opens it in VLC.

If Finder still shows old icons for .cptv files, close and reopen the Finder window.

To remove it later, run this in Terminal:
sudo "/Library/Application Support/cptv-native-viewers/uninstall.sh"
